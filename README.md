A program that writes the funniest one-line review of its own Monday.

Run it with Node 22:

```sh
node main.ts
```

It writes exactly one line to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` when set) — a single-line, under-200-character review of the entrant's own Monday, deterministically, byte-identical on every run.
